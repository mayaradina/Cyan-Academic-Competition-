# Cyan Academic Competition 2026 Website

Official Landing Page & Registration System for **Cyan Academic Competition 2026**, organized by **Departemen Akademik, Riset, dan Teknologi (AKSI) HMSI Telkom University** in collaboration with **Enterprise Data Management (EDM) Laboratory** and **Enterprise Infrastructure Management (EIM) Laboratory**.

---

## 🌟 Key Features

1. **Futuristic Cyberpunk Cyan Design System**:
   - Deep navy background (`#050B18`) with glowing cyan & neon accents (`#00F2FE`, `#00FFCC`).
   - Glassmorphic UI cards & floating header.
   - Interactive 3D Constellation Canvas background with mouse repulsion physics.
   - Light & Dark mode toggle with saved preference.

2. **Official Proposal Timelines**:
   - **Open Registration Batch 1**: 1 – 10 Oktober 2026
   - **Open Registration Batch 2**: 11 – 18 Oktober 2026
   - **Extended Registration (Opsional)**: 19 – 20 Oktober 2026
   - **Technical Meeting Peserta**: 23 Oktober 2026
   - **Pelaksanaan Lomba / Penyisihan**: 24 Oktober – 23 November 2026 (Penyisihan: 31 Okt)
   - **Penjurian & Pengecekan Hasil**: 21 – 23 November 2026
   - **Pengumuman Finalis**: 24 November 2026
   - **Technical Meeting Final**: 25 November 2026
   - **Babak Final (2 Hari)**: 27 – 28 November 2026
   - **Awarding Ceremony**: 1 Desember 2026

3. **2 Competition Branches (University Students)**:
   - 🤖 **Machine Learning Competition**: Organized by EDM Laboratory.
   - 🛡️ **Capture The Flag (CTF)**: Organized by EIM Laboratory.

4. **Interactive Extras**:
   - Live Countdown Timer to Batch 1 deadline.
   - 3D Interactive Slide Guidebook Viewer.
   - HTML5 Arcade Mini Game ("Cyan Tech Rush") with high score system.
   - Online Registration System with Digital Ticket Generator (`CYAN-2026-XXXX`) + QR Code preview & status lookup portal.

## 🚀 How to Run Locally

You can run this project using any local web server:

### Option 1: Python HTTP Server
```bash
python -m http.server 9000
```
Then open `http://localhost:9000` in your browser.

### Option 2: VS Code Live Server Extension
1. Open the project folder in **VS Code**.
2. Right click `index.html` -> **Open with Live Server**.
